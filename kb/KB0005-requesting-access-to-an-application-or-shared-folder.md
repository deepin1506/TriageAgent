# Requesting access to an application or shared folder

## Symptoms

The user gets 'access denied' when opening an application, a SharePoint site or a shared network folder they need for work.

## Resolution

1. Raise an access request naming the exact application or folder path.
2. Include the business reason and the approving manager.
3. Access is granted to a role group, not to individuals, once the manager approves.

## When to escalate

Identity & Access Management fulfils approved requests. Urgent access for a blocked business process needs the manager's approval in the ticket.
