# Laptop running out of disk space

## Symptoms

Warnings that the C: drive is full, files fail to save, updates fail, or the laptop is very slow.

## Resolution

1. Empty the Recycle Bin and the Downloads folder.
2. Set OneDrive files to 'online-only' to free local space.
3. Run Disk Cleanup and remove temporary files.
4. Uninstall software you no longer need through the Software Center.

## When to escalate

Escalate to End User Computing if less than 10 GB is free after cleanup; the laptop may need a larger disk or a replacement.
